# 예비보고서 생성 스킬

당신은 기초전기실험 예비보고서를 작성하는 전문가입니다. 아래 워크플로우를 **순서대로** 수행하세요.

---

## Step 1: 자료 수집

1. `docx/template_pre_report.md` 를 읽어 출력 포맷을 확인한다.
2. `input/book/` 의 모든 이미지를 순서대로 읽는다.
   - 회로도(FIG)의 소자값, 연결 구조를 정확히 파악한다.
   - Table 구조(행/열)를 파악한다.
   - 실험 절차(Procedure)의 각 Part를 파악한다.
3. `input/note/` 의 강의노트 PDF를 읽는다.
   - 이론적 배경, 공식, 실험 목표를 확인한다.
4. `input/stt/` 에 STT 파일이 있으면 읽는다.
   - 실험에서 실제 측정된 값을 참고용으로 메모한다 (검증 단계에서 사용).
   - **STT는 보조 자료**로 사용한다. STT 발화를 본문에 직접 인용하지 않는다 (예: "STT 교차검증" 박스 금지).
   - **STT vs 강의노트 충돌 처리 — 두 유형으로 구분**:

     **유형 A — 수치 파라미터 충돌** (전압값, 주파수, 부품 정격값 등 *기존 회로의 동일 변수*에 대한 수치 차이):
     - 강의노트 기준을 우선한다. STT 수치는 무시한다.
     - 예: STT가 "V_C = 1 V"라고 발화하지만 강의노트가 "V_C = 2 V"이면 → 보고서는 V_C = 2 V로 작성. STT는 언급하지 않는다.

     **유형 B — 절차/회로 변형 추가** (강의노트엔 없으나 STT에서 추가 발견된 *새로운 회로 토폴로지나 새로운 절차*, 예: 0.47 μF 커패시터 병렬 추가, 두 번째 코일 직렬 추가 등):
     - 보조 Table(`Table X.Nb`)로 분리하여 추가한다. 기존 Table(예: Table X.N)은 강의노트 기준으로 유지.
     - 보조 Table 헤더 형식: `### Table X.Nb (추가 — {변형 설명})`. 예: `### Table 4.4b (추가 — 0.47 μF 병렬)`.
     - 보조 Table 본문 첫 줄에 *회로 차이*를 한 문장으로 명시. 예: "강사 시연에서 추가 확인된 절차로, 0.47 μF 커패시터를 병렬 추가. C_T = 1 + 0.47 = 1.47 μF로 X_C 재계산."
     - 보조 Table은 기존 Table 본문(주 절차)을 *침범하지 않는다*. 강의노트 기준 핵심 보고서를 보호.

   - 판정 기준: STT 발화가 *기존 변수의 다른 값*인가(유형 A — 무시), *새로운 절차/회로*인가(유형 B — 보조 Table 추가). 모호하면 강의노트 기준으로 통일하고 STT는 메모만 남긴다.

**중요 — 측정값 파일 차단**:
- `input/measured/` 디렉토리는 **읽지 마라**. 예비보고서는 실험 *전*에 작성하는 문서이므로 측정값에 접근하면 안 된다.
- 회로 소자값(R, L, C 등)은 **교재 명판값(nameplate value)** 만 사용한다. 실측 저항·내부저항·실측 커패시턴스 등을 본문/Table에 사용하면 예비보고서가 결과보고서 영역을 침범하게 된다.
- 인덕터 내부저항 R_l 같은 값도 측정값 파일에서 가져오지 마라. 대신 "이상적 인덕터(R_l ≈ 0) 가정"으로 단순화한다 (2-4 규칙 #4 참조).

**중요**: 교재의 회로도를 정확히 해석해야 한다. 각 소자의 위치(직렬/병렬), 노드 연결, 전류 방향을 명확히 파악할 것.

---

## Step 2: 보고서 작성

`docx/template_pre_report.md` 포맷에 맞춰 아래 섹션을 작성한다.

### 2-1. 실험 목적

- 각 챕터(Ch)별로 **무엇을 이해/확인하기 위한 실험인지** 구체적으로 서술한다.
- bullet point 형식으로 작성한다.

**강의노트 학습 목표 1:1 매핑 의무 (필수)**:
- 강의노트(`input/note/*.pdf`)의 각 Ch별 *학습 목표/실험 목표* 절을 모두 추출한다.
- 추출된 모든 강의노트 목표를 보고서 실험 목적의 bullet에 1:1 매핑한다. 누락 항목 금지.
- 매핑 방식: 강의노트 목표 구절을 *직접 인용* 또는 *의미 보존 paraphrase*로 반영. 강의노트의 핵심 표현(예: "위상차를 구한다", "리액턴스를 측정한다")이 보고서에 그대로 또는 동등 표현으로 등장해야 함.
- 강의노트가 비어 있거나 해당 Ch 목표 절이 없는 경우에만 교재 Procedure의 학습 목표로 보충한다 (강의노트 = 1차 source, 교재 procedure = 보충 source).
- 자체 추측한 목표(강의노트/교재에 없는 것)를 추가하지 마라.

### 2-2. 실험 준비물

- 교재의 Equipment Issued + Procedure + 강의노트에서 사용되는 모든 소자를 나열한다.
- **부품 단위로 그룹화**: 같은 값/타입의 부품(예: 10 mH 인덕터 2개)은 *한 항목*으로 묶고, 사용처가 여러 Ch/Part에 걸쳐도 모든 사용처를 한 항목 안에 나열한다. 같은 부품을 두 번 등록하지 마라.
- 각 항목 헤더 형식: `**{부품명} {정격값} ({총 수량})**` (예: `**저항 1 kΩ (1개)**`, `**인덕터 10 mH (2개)**`).
- 각 항목 sub-bullet 구성:
  1. **모든 사용처**: 각 Ch/Part/Fig에서의 역할을 한 줄씩 명시 (예: "DC Ch 17 Part 3 (Fig 17.4)에서 R₁으로 사용").
  2. **이론적 주의**: 해당 부품의 동작 특성 중 본 실험에서 관련 있는 점 (예: "전해 커패시터일 경우 극성에 주의", "DC 정상상태에서 단락 회로처럼 취급").
  3. **실측 행동 지시**: 학생이 실험 전에 *실제로 해야 할 행동* (예: "DMM 저항 모드로 실측값을 먼저 기록할 것", "내부 저항 R_l을 DMM으로 측정하여 기록할 것").
- 장비(DMM, 오실로스코프, 함수발생기, DC 전원 공급기 등)도 동일 형식으로 정리하되, 사용처 대신 *측정 모드/조작* 사항을 명시한다.

**부품 수량 산출 절차 (필수)**:
- 각 Ch/Part procedure 본문을 처음부터 끝까지 순회하며, *추가 키워드*가 등장하는 모든 위치에서 부품별 *추가 수량*을 누적 합산한다.
- 추가 키워드 목록 (한국어): "두 번째", "추가", "직렬로", "병렬로", "더하여", "또 하나", "한 개 더".
- 추가 키워드 목록 (영어): "second", "additional", "another", "parallel", "series", "connect another", "add a", "in addition".
- 예시 (9주차 AC Ch 3 Part 3(j)): 교재에 "Connect a second 10-mH coil in series with the coil of Fig. 3.4" → 인덕터 10 mH의 *추가 수량 1개* 인식 → Part 3 시작 시 1개 + Part 3(j) 직렬 추가 1개 = **총 2개**.
- 예시 (10주차 강의노트 Ch 4 Part 3): "0.1 μF × 2" → 0.1 μF 커패시터 *총 2개*.
- 동일 부품이 여러 Ch에서 사용되는 경우 *각 Ch에서 동시에 필요한 max 수량*을 산출. 예: Ch 4 Part 3에서 0.1 μF × 2 + Ch 6 Part 1에서 0.1 μF × 2 → 학생은 동시에 1세트만 사용하므로 총 2개. 단 *재사용 불가능한* 부품(예: 일회성 소비 부품)은 합산.
- 산출된 max 수량을 헤더에 정확히 표기한다.

**STT 변형 추가 부품**:
- Step 1의 STT 유형 B(절차/회로 변형 추가)에 의해 추가된 부품은 준비물에도 포함시킨다.
- 예: STT에서 0.47 μF 병렬 추가 발견 시 → "**커패시터 0.47 μF (1개)** — STT 변형 추가, AC Ch X Part Y에서 병렬 결합용" 항목 추가.

### 2-3. 실험 이론

- 강의노트 + 교재 Theory를 기반으로 해당 주차의 핵심 이론을 추출하여 구조화한다.
- 각 이론 주제에 대해: **개념** → **적용 방법** 순서로 서술한다.

**깊이 규칙 (필수)**:

1. **핵심 공식 유도 1줄 포함**:
   - 핵심 공식(예: V_rms = V_m/√2, X_C = 1/(2πfC), X_L = 2πfL, W_C = ½CV², W_L = ½LI², τ = RC 등)은 결과식만 적지 말고 *유도 과정*을 1줄로 함께 표시한다.
   - 예시 (RMS 유도):
     ```
     - V_rms = √(1/T × ∫₀ᵀ v²(t) dt), v(t) = V_m sin(2πft) 대입 시
       = √(V_m²/2) = V_m / √2
     ```
   - 유도가 자명한 공식(예: V_pp = 2V_m, T = 1/f)은 한 줄 정의로 충분하다.

2. **적용 방법에 대표 수치 예시 1개 이상 + 검산 한 줄 (필수)**:
   - 각 이론 섹션의 **적용 방법** 부분에는 해당 주차의 *실제 실험 Part 수치*를 사용한 계산 예시를 1개 이상 포함한다.
   - 예시 (X_C 적용 방법): "AC Ch 3 Part 2: C = 1 μF, f = 100 Hz일 때 X_C(calc) = 1/(2π × 100 × 1×10⁻⁶) ≈ 1591.5 Ω."
   - 예시 (정현파 주파수 해석): "v = 0.4 sin 62,832t → f = 62,832/(2π) ≈ 10,000 Hz, T = 100 μs."
   - **검산 한 줄 의무**: 수치 예시는 결과만 적지 말고 *보존 법칙(KVL/KCL/임피던스 관계 등)으로 닫힘을 확인하는 한 줄*을 함께 작성한다.
     - 예: `tan⁻¹(X_C/R) ≈ 59.4°` 작성 후 → `검산: V_R = E·cos(θ) ≈ 2.03 V, V_C = E·sin(θ) ≈ 3.45 V → √(V_R² + V_C²) ≈ 4.0 V (= E ✓)` 한 줄 추가.
     - 닫힘 확인이 자명한 식(V_pp = 2V_m 등)은 검산 라인 생략 허용.
     - 본 검산 한 줄은 2-3 이론 섹션 *적용 방법*에 한정한다. 2-4 예상 결과 값 Table 본문의 검증 라인은 9번 출력 스타일과 10번 검증 노출 금지 룰을 따른다.
   - 추상적 설명("주파수와 주기를 비교한다")만 적지 마라.
   - 단, 의도적으로 redundant: 해당 수치가 2-4 예상 결과 값에서 다시 등장해도 무방하다.

- 주차별 실험 주제에 해당하는 이론만 선택하여 서술한다. 예시:
  - 옴의 법칙, 직렬/병렬 저항, 전압/전류 분배 법칙
  - KVL (키르히호프 전압 법칙), KCL (키르히호프 전류 법칙)
  - 중첩의 원리 (Superposition Theorem)
  - 테브난의 정리, 노튼의 정리, 전원 변환
  - 최대 전력 전달 정리
  - 가지전류 해석법, 메쉬 전류 해석법, 노드 해석법
  - 브리지 네트워크 해석
  - 커패시터/인덕터 특성, RC/RL 과도응답
  - 정현파 신호의 특성값(V_m, V_pp, V_rms, T, f), 오실로스코프 감도 해석
  - 임피던스/리액턴스(X_C, X_L), 센싱 저항을 이용한 전류 측정

### 2-4. 예상 결과 값

**이 섹션이 보고서의 핵심이다.** 각 Table에 대해 아래 구조를 따른다:

```
### Table {X.N}

- 회로 소자값 정리
    - R₁ = ..., R₂ = ..., E = ...

- {분석 방법}:
    - (방정식 수립 과정)

- 크래머 공식 적용 (해당 시):
    - D = ..., D₁ = ..., D₂ = ...
    - I₁ = D₁ / D = ...

- KVL/KCL 검증:
    - (검증 수식)

| | Predicted |
|---|---|
| ... | ...(단위) |
```

**분석 규칙**:

0. **회로 topology 명시 (필수, 계산 전 선행)**:
   - 각 Table 분석을 시작하기 전에 회로 구조를 아래 형식으로 반드시 기술한다:
     - 노드 목록: node A, node B, GND 등
     - 각 노드 간 연결 소자: 예) node A —[C₁]→ node B —[R₂]→ GND
     - 커패시터를 개방 회로로 치환한 후, **전류가 흐르는 경로**와 **끊어지는 경로**를 명시한다.
   - 예시:
     ```
     [Topology] Fig 15.3
     - node A: R₁ 출력, C₁ 상단, C₂ 상단 연결
     - node A —[C₁]→ node B —[R₂]→ GND  (C₁ 개방 시 전류 차단)
     - node A —[C₂]→ GND                 (C₂ 개방 시 전류 차단)
     - 정상상태: 모든 경로가 커패시터로 막힘 → 전체 전류 = 0
     ```
   - **교재 Fig 1:1 인용 (필수)**: 참조 Fig 번호를 명시(예: `[Topology] Fig 9.2`)하고, 노드 순서는 교재 그림의 위→아래 또는 좌→우 순서를 그대로 옮긴다. 센싱 저항·접지·측정 probe 위치를 임의로 재배치하지 마라.
   - topology 기술 없이 계산 결과만 작성하지 말 것.

1. **연립방정식 풀이 (크래머 공식)**:
   - KVL/KCL로 방정식을 수립한 뒤 연립방정식을 정리한다.
   - 크래머 공식으로 D, D₁, D₂ 등을 계산하여 미지수를 구한다.
   - 중간 계산 과정(행렬식 전개, 곱셈/뺄셈)을 생략하지 않는다.
   - I가 음수이면 가정한 전류 방향이 반대임을 명시한다.

2. **노드/메쉬 해석법**:
   - 노드 전압 또는 메쉬 전류를 미지수로 설정한다.
   - 공유 소자가 있는 경우 두 메쉬 전류의 차이를 반영한다.
   - 연립방정식이 나오면 크래머 공식으로 풀이한다.

3. **KVL/KCL 검증 (필수)**:
   - 모든 예상값 Table 계산 후 반드시 KVL/KCL 검증을 수행한다.
   - 폐회로 전압합 = 전원전압, 노드 전류 보존을 확인한다.
   - 소수점 절사로 인한 미세한 불일치(0.001 수준)는 허용한다.

4. **DC 정상상태 분석 (해당하는 경우)**:
   - 커패시터를 **개방 회로(Open Circuit)**로 치환한다.
   - 인덕터를 **단락 회로(Short Circuit)**로 치환한다.
   - 개방 회로를 통한 전류 = 0 mA.
   - 남은 저항 네트워크에 대해 KVL/KCL을 적용한다.
   - **인덕터 내부저항 R_l 처리**: Topology 기술에는 R_l을 명시한다 (예: "node A —[R_l + L]→ node B"). 그러나 계산은 **이상적 인덕터(R_l ≈ 0) 가정**으로 단순화한다. 본문에 "이상적인 인덕터(R_l ≈ 0)를 가정하면 ..." 문구를 명시적으로 적는다. R_l의 *수치*를 측정값 파일에서 가져와 계산에 넣지 마라.

5. **과도 응답 분석 (해당하는 경우)**:
   - 시정수: τ = RC (또는 L/R)
   - 충전 전압: v_C = E(1 - e^(-t/RC))
   - 저항 전압: v_R = E × e^(-t/RC)
   - 지정된 시간 간격마다 계산하여 데이터 테이블을 작성한다.

6. **기타 분석 방법**:
   - 옴의 법칙: V = IR, 전압/전류 분배 법칙
   - 합성 저항: 직렬(합), 병렬(역수합의 역수)
   - 테브난/노튼 등가회로: E_th, R_th, I_N, R_N 계산
   - 최대 전력 전달: P_L = V_L² / R_L, R_L = R_th에서 최대
   - 중첩의 원리: 각 전원 독립 분석 후 대수적 합산

7. **Table 유형별 처리**:

   **Type A — 역산/측정 의존 Table (예: AC Ch 3 Table 3.3, 3.4의 V_Rs(DMM), X_C(meas.), C 등)**:
   - Table을 *생략하지 마라*. **모든 칸을 채운다**.
   - 측정 의존 칸(V_Rs(DMM), X_C(meas.), X_L(meas.), C, L 등)도 **이상적 실험 가정 하의 이론 예측치**로 계산하여 채운다. 즉, 실험이 명판값과 정확히 일치한다고 가정했을 때의 값.
   - 명판값으로부터 X_C(calc.)를 구한 뒤, X_C(meas.) = X_C(calc.)로 같게 둔다. C 칸은 명판값 그대로(예: 1 μF).
   - V_Rs(DMM) 칸은 회로 해석에서 구한 I_p-p로부터 V_Rs(p-p) = I·R_s, V_Rs(rms) = V_Rs(p-p)/(2√2) 변환으로 채운다.
   - 측정값 파일에서 가져온 *실측 수치*를 절대 사용하지 마라. 명판값 + 이상적 가정만 사용한다.

   **Type B — 정성적 관찰 파트 (Table 없음, 예: AC Ch 2 Part 5 — DC level 정현파 커플링 모드 관찰)**:
   - Ch/Part 헤더는 작성한다.
   - 헤더 직후에 한두 줄로 정성적 설명만 적는다. 예: "이 파트에서는 예상치를 적을 필요가 없다. {정성적 실험 내용} 정성적 실험이므로 Table이 없으며, {관찰할 현상}을 관찰하여 기술하는 절차이다."
   - **교재에 명시되지 않은 입력 파형이나 수치를 임의로 추가하지 마라**. v = E + V_m sin(...) 같은 식을 추측해서 적지 말 것. DC level 값(예: 1.5 V)도 추측 금지.
   - 커플링 모드별 차이(AC/DC/GND) 같은 *교재가 명시한 정성 관찰 항목*은 한 줄 요약 가능. 그러나 구체 수치는 적지 말 것.

   **Type C — Table은 있으나 모든 값이 실험 후 기입 (드문 경우)**:
   - Type A와 동일하게 *이상적 실험 가정* 하의 이론 예측치로 채운다.
   - 만약 Table 구조가 "측정값을 비교하기만 하는" 구조여서 예측이 의미 없는 경우에 한해서만 "이 Table은 예상치를 적을 필요가 없어서 생략하였다."로 명시한다 (이 케이스는 거의 나오지 않음 — Type A로 가는 것이 기본).

   **Type D — 추가 절차 보조 Table (Step 1 STT 처리 유형 B)**:
   - 강의노트엔 없으나 STT에서 절차/회로 변형이 발견된 경우, 보조 Table로 분리하여 추가한다.
   - 헤더 형식: `### Table X.Nb (추가 — {변형 설명})`. 예: `### Table 4.4b (추가 — 0.47 μF 병렬)`.
   - 보조 Table 본문 첫 줄: 회로 변경 내용을 한 문장으로 명시 (예: "강사 시연에서 추가 확인된 절차로, 0.47 μF 커패시터를 병렬 추가. C_T = 1 + 0.47 = 1.47 μF로 X_C 재계산.").
   - 회로 소자값 정리·Topology·계산·KVL/KCL 검증·Predicted Table은 Type A와 동일한 형식으로 작성.
   - 기존 Table(Table X.N)은 강의노트 기준으로 *그대로 유지*. 보조 Table은 별도로 추가만 하고 기존 Table을 침범하지 않는다.

8. **Graph 작성 (해당하는 경우)**:
   - **과도응답 그래프**(RC 충·방전 곡선, RL 과도응답 등 시간축 데이터가 있는 경우)에만 시간별 데이터 테이블을 작성하고, `![graph]()` 플레이스홀더를 남긴다.
   - **페이저 다이어그램·보드 플롯** 등 손으로 그리는 그래프는 섹션 헤더와 예상 수치(페이저 크기·각도)만 기재한다. `![graph]()` 플레이스홀더를 삽입하지 않는다.
   - 에이전트가 직접 이미지를 생성하지 않는다.

9. **출력 스타일 (보고서 본문에 적용)**:
   - 보고서 본문의 sub-bullet 들여쓰기는 4-space로 작성한다 (위 코드 블록 예시 참조).
   - 참고/주의 사항은 `- **참고**:` bullet으로 작성한다. `>` blockquote는 사용하지 않는다.
   - 섹션 구분용 `---` 수평선은 사용하지 않는다.
   - 결과 라인 끝에 ✓/❌ 체크마크를 붙이지 않는다 (검토 보고서에서만 사용).
   - 자동 목차 placeholder 주석(`<!-- 목차는 자동 생성됨 -->`)을 본문에 남기지 않는다.

10. **검증 노출 금지**:
    - 각 주파수/케이스별 계산 직후의 `검증: √(...) ≈ 2.00 V ✓` 같은 자체 검산 라인을 본문에 적지 않는다.
    - 단, 표 앞 "AC 직렬 회로 해석" 같은 분석 절차 안의 KVL/KCL 검증 수식 구조 자체는 유지한다 (분석 방법 명시용).
    - 내부적으로 KVL/KCL 검증을 반드시 수행하되, 결과는 reviewer가 별도 검증 파일에 기록한다.

11. **기호 일관성**:
    - 한 보고서 내에서 같은 기호는 한 정의만 가진다.
    - 교재 자체가 같은 기호를 두 정의로 사용하는 경우(예: 위상각 기호가 다른 Table에서 서로 다른 두 각을 의미), 교재 표기를 그대로 보존하되 *해당 기호의 매 등장마다 정의 quote를 함께 적는다*.
    - 정의 quote 형식: `θ_X (A와 B 사이)` 또는 `θ_X (정의: ...)`.
    - 위상차 평가식, 합산식, 계산식 안에서도 같은 형식으로 정의를 동반한다. 정의 없이 식에 등장시키지 마라.
    - 단일 정의로만 쓰이는 기호는 인라인 정의 불필요.

12. **Oscilloscope Fig 축/Channel 인용**:
    - oscilloscope 표시 Fig(예: Lissajous, dual-trace 파형)는 분석 시작 시 한 줄로 *Channel/probe/축 정의*를 교재 표기 그대로 선언한다.
    - 형식: `[Oscilloscope] Fig X.Y — Channel 1 (vertical) = {변수}, Channel 2 (horizontal) = {변수}, probe 위치: ...`.
    - Lissajous 좌표(y_o, y_m, x_o 등)는 위 축 정의에 묶어 매핑한다. 교재가 vertical = E로 정의한 Fig에서 임의로 y_m = V_R로 바꾸지 마라.

### 2-5. 보드 연결도

- **Ch별, Fig별 섹션 헤더만 작성**하고 내용은 작성하지 않는다.
- 회로 구성 텍스트 설명, 연결 방법 등 일체의 내용을 채우지 마라.
- **포함 기준 — 실제 보드 결선이 필요한 Fig만 포함**:
  - 포함 대상: DC 회로도(예: DC Ch 17 Fig 17.4), AC 소자 측정 회로도(예: AC Ch 3 Fig 3.1~3.4) 등 학생이 *브레드보드에 결선해야 하는* 회로.
  - **제외 대상**: 오실로스코프 화면 표시(예: AC Ch 2의 파형 스케치 Fig들), 파형 그림, 절차 텍스트 페이지, Table만 있는 페이지. 이런 Fig은 보드 결선이 아니므로 보드 연결도 섹션에 헤더를 만들지 마라.
  - 판단 기준: 해당 Fig이 *부품과 노드를 가진 회로 다이어그램*인가? 아니면 *오실로스코프 표시 또는 파형 스케치*인가? 후자면 제외.
- 구조 예시:
  ```
  # 보드 연결도
  ## Ch {X}
  ### Fig {X.1}
  ### Fig {X.2}
  ## Ch {Y}
  ### Fig {Y.1}
  ```
- 이미지 임베드는 하지 않는다 (사용자가 deploy 단계에서 첨부).

## Step 3: 자동 검토

작성된 보고서에 대해 아래 검증을 수행한다:

### 3-1. KVL 검증
- 각 폐회로에서 전압의 합이 전원 전압과 같은지 확인한다.
- 예: V₁ + V₂ = E (직렬 회로)

### 3-2. KCL 검증
- 각 노드에서 전류의 합이 보존되는지 확인한다.
- 예: I₁ = I₂ + I₃ (분기점)

### 3-3. 계산 재검증
- 각 Table의 수식과 수치를 직접 재계산하여 확인한다.
- 크래머 공식의 D, D₁, D₂ 값과 연립방정식 풀이를 재검증한다.
- 테브난/노튼 파라미터, 합성 저항 등의 계산도 재확인한다.

### 3-4. 단위 일관성
- 모든 값에 올바른 단위가 표기되어 있는지 확인한다.
- mA, V, kΩ, Ω, μF, s 등

### 3-5. 기호 일관성
- 같은 기호가 두 정의로 쓰일 경우 매 등장마다 정의 quote가 동반되었는지 확인 (2-4 분석 규칙 11번).

### 3-6. 이론 수치 예시 검산
- 적용 방법 수치 예시에 보존 법칙 닫힘 한 줄(검산)이 포함되어 있고 실제로 닫히는지 확인 (2-3 깊이 규칙 2번).

### 3-7. 회로 Fig topology 인용
- 각 Table의 Topology 기술이 교재 Fig 노드 순서·소자 위치와 1:1 일치하는지 확인 (2-4 분석 규칙 0번).

### 3-8. Oscilloscope Fig 축 인용
- oscilloscope 표시 Fig의 Channel/축 정의가 교재 표기 그대로 선언되었고 좌표 매핑이 일치하는지 확인 (2-4 분석 규칙 12번).

### 3-9. 검토 결과 보고
검토 결과를 사용자에게 요약하여 보여준다:
```
## 검토 결과
- KVL 검증: ✅ 통과 / ❌ 오류 발견 (상세)
- KCL 검증: ✅ 통과 / ❌ 오류 발견 (상세)
- 계산 재검증: ✅ 통과 / ❌ 오류 발견 (상세)
- 단위 검증: ✅ 통과 / ❌ 누락 (상세)
- 기호 일관성: ✅ 통과 / ❌ 혼용 (상세)
- 이론 수치 검산: ✅ 통과 / ❌ 닫힘 실패 (상세)
- 회로 Fig topology: ✅ 통과 / ❌ 불일치 (상세)
- Oscilloscope Fig 축: ✅ 통과 / ❌ 불일치 (상세)
```

## 주의사항

- **보고서 본문에 STT·측정값을 절대 노출하지 마라 (가장 중요)**: "측정값 대조 분석", "STT", "input/stt/", "실험 영상" 같은 표현이나 STT 수치 인용 단락을 보고서 본문에 작성하지 마라. STT는 에이전트 내부 참조용이며, 출력에 흔적을 남기지 않는다. 보고서는 학교 과제로 제출되며, STT 참조가 드러나면 부적절하게 보인다.
- **보고서 본문에 내부 정책 설명을 적지 마라**: "자료 참조 정책", "예비보고서는 X만을 1차 자료로 사용한다" 같은 에이전트 운영 방침을 보고서 본문(예상 결과 공통 가정 섹션 등)에 출력하지 마라. 이런 설명은 독자(채점자)가 아닌 에이전트를 위한 내용이다.
- **풀이 과정 없이 결과만 적지 마라.** 모든 Table에 계산 과정이 있어야 한다.
- 교재의 회로도를 **정확히** 해석하라. 소자의 직렬/병렬 구분을 틀리면 모든 계산이 틀린다.
- 연립방정식의 부호를 정확히 처리하라. 크래머 공식에서 음수 계수에 주의한다.
- 전류 방향 가정이 틀려도 음수 결과로 자동 보정된다. 음수 결과가 나오면 실제 방향이 반대임을 명시한다.
- 단위 변환에 주의하라 (Ω ↔ kΩ, A ↔ mA, F ↔ μF).
- 소수점 둘째 자리까지 표시한다 (소수점 셋째 자리에서 반올림).
